# ساعاتي الإضافية

تطبيق عربي خفيف لتسجيل ساعات العمل الإضافي وحساب قيمتها بسعر ثابت قدره 1,500 ريال يمني للساعة.

## ما يقدمه

- واجهة عربية كاملة واتجاه RTL ومناسبة لشاشة الجوال.
- تحديد تلقائي لنهاية الدوام: 2:00 م من السبت إلى الأربعاء، و1:00 م يوم الخميس.
- يوم الجمعة إجازة؛ كل المدة المسجلة فيه تعد وقتًا إضافيًا.
- لوحة رئيسية لإجمالي الشهر، سجل قابل للتعديل والحذف، وتقارير يومية وأسبوعية وشهرية.
- تخزين البيانات محليًا على الجهاز، من دون حساب أو خادم.

## التشغيل محليًا

يتطلب Node.js 20 أو أحدث:

```bash
npm install
npm run dev
```

## تحويله إلى تطبيق أندرويد

بعد تثبيت Android Studio وتهيئة بيئة Android SDK:

```bash
npm install
npm run android:add
npm run android:sync
npm run android:open
```

بعد ذلك استخدم Android Studio لتشغيل التطبيق على جهاز أو لإنشاء ملف APK/AAB. عند أي تعديل للواجهة، نفّذ `npm run android:sync` مرة أخرى.

## النشر على GitHub Pages

المشروع يتضمن GitHub Action جاهزًا في `.github/workflows/deploy-pages.yml`. بعد رفع المشروع إلى مستودع GitHub ودفع فرع `main`، فعّل **GitHub Pages → Source: GitHub Actions** من إعدادات المستودع. سيُنشر التطبيق تلقائيًا عند كل تحديث.
